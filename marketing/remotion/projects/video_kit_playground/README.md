# video_kit_playground

Remotion playground project for visual QA of `@lux/video-kit` components.

## Compositions

- `VideoKitTerminalShowcase`
- `VideoKitLuxUiShowcase`
- `VideoKitCodexSessionReplica`
- `VideoKitCodexSessionComparison`

## Commands

- `npm run dev`: open Remotion Studio and inspect compositions.
- `npm run build`: bundle the project.
- `npm run lint`: lint and type-check source files.

## Notes

- This project imports from `../../../../packages/video-kit/src` inside composition files.
- It is a QA sandbox and not a campaign video project.
